Quiz Creation Tips
Question Design
  • Use clear, unambiguous language
  • Include a variety of question types
  • Avoid trick questions
  • Test key concepts, not obscure details
  • Provide plausible distractors for multiple choice
Timing
  • Set realistic time limits
  • Consider reading time
  • Allow time for review
  • Test timing with sample questions
Scoring
  • Assign appropriate point values
  • Consider partial credit options
  • Set clear passing criteria
  • Balance difficulty and scoring
Academic Integrity
  • Randomize question order
  • Use question banks
  • Set appropriate time limits
  • Consider proctoring options
